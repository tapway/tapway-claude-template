# /brainstorming — Explore Approaches

Start an exploratory brainstorming session before writing code.

## Steps

1. **Invoke the `brainstorming` skill**
2. Clarify the problem and requirements
3. Explore 2-3 implementation approaches with trade-offs
4. Identify risks, dependencies, and edge cases
5. Recommend a direction

## Usage

```
/brainstorming                          # General brainstorming
/brainstorming How to handle file uploads?
/brainstorming Options for real-time notifications
```
