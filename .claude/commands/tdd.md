# /tdd — Test-Driven Development

Implement a task using the red-green-refactor cycle.

## Steps

1. **Invoke the `tdd` skill**
2. **Red** — write a failing test for the next piece of functionality
3. Verify the test fails with the expected error
4. **Green** — write just enough code to make the test pass
5. **Refactor** — clean up while keeping tests green
6. Commit with a descriptive message

## Usage

```
/tdd                              # Start TDD cycle for current task
/tdd Implement the login endpoint
/tdd Task 1 from the plan
```
