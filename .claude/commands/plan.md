# /plan — Write an Implementation Plan

Create a detailed, concrete implementation plan for a multi-step task.

## Steps

1. **Invoke the `writing-plans` skill**
2. Break the feature into bite-sized tasks (2–5 minutes each)
3. Map every file to create or modify
4. Ensure no vague steps or placeholders
5. Save the plan to `docs/plans/[feature-name].md`

## Usage

```
/plan                              # Plan current feature
/plan subscription billing         # Plan a specific feature
/plan Implement user auth          # Plan from a description
```
